# Atributos de calidad
 
| ID | Atributo | Escenario de calidad |
|---|---|---|
| AC01 | Rendimiento | El filtrado y la carga del catálogo deben responder en menos de 2 segundos incluso con miles de productos activos. |
| AC02 | Disponibilidad | El flujo de checkout debe seguir operativo aunque el servicio de envío esté temporalmente caído. |
| AC03 | Escalabilidad | El sistema debe poder atender picos de tráfico (ej. campañas por el "Día de la Mascota") sin degradar el checkout. |
| AC04 | Seguridad | Las credenciales, datos de pago y direcciones de los clientes deben cifrarse y protegerse contra accesos no autorizados. |
| AC05 | Mantenibilidad | Un cambio en la lógica de un módulo (ej. carrito) no debe requerir modificar el módulo de catálogo. |
