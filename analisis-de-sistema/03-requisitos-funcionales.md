# Requisitos funcionales
 
| ID | Requisito funcional |
|---|---|
| RF01 | El sistema debe permitir filtrar y ordenar productos por categoría, precio y tipo de mascota. |
| RF02 | El sistema debe permitir a un seller crear, editar y eliminar publicaciones de productos con imágenes y stock. |
| RF03 | El sistema debe permitir agregar, actualizar cantidad y eliminar ítems del carrito. |
| RF04 | El sistema debe permitir generar un pedido seleccionando dirección de entrega y método de pago. |
| RF05 | El sistema debe permitir a un administrador aprobar o rechazar solicitudes de registro de sellers. |
| RF06 | El sistema debe notificar al cliente los cambios de estado de su envío. |
| RF07 | El sistema debe generar una alerta cuando el stock de un producto caiga bajo un umbral definido. |
| RF08 | El sistema debe emitir y poner a disposición del cliente el comprobante de pago de cada pedido. |
