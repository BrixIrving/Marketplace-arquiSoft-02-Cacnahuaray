# Restricciones
 
| ID | Restricción | Descripción |
|---|---|---|
| RC01 | Aplicación web | Debe ser accesible desde navegador sin instalación adicional. |
| RC02 | Control de versiones | Código gestionado con Git en repositorio compartido en GitHub. |
| RC03 | API REST | La comunicación frontend–backend debe darse por API REST. |
| RC04 | Pasarela de pago | Integración obligatoria con una pasarela externa para cobros. |
| RC05 | Servicio de envío | Integración obligatoria con un servicio externo de logística. |
| RC06 | Presupuesto | El proyecto debe usar únicamente infraestructura y herramientas gratuitas o de nivel académico. |
| RC07 | Plazo académico | La primera propuesta arquitectónica debe entregarse dentro del cronograma del curso IS-488. |
